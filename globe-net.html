Cara pasang

  1. Kirim lokasi

    Kirim titik lokasi ke admin untuk cek jangkauan.

  2. Pilih paket

    Admin bantu memilih sesuai kebutuhan.

  3. Jadwal pasang

    Teknisi datang sesuai jadwal yang disepakati.

  4. Internet aktif

    Pembayaran bulanan, tanpa ribet.

Tanya jawab

Berapa biaya pemasangan?

Biaya pasang tergantung lokasi dan paket. Tanyakan ke admin saat cek jangkauan.

Kalau ada gangguan, hubungi siapa?

Hubungi admin Globe.Net lewat WhatsApp. Teknisi kami ada di Sukabumi.

Apakah ada kontrak minimal?

Tanyakan ketentuan kontrak ke admin sebelum pemasangan.

Tanya langsung ke admin

Pilih kebutuhan Anda. Tombol membuka WhatsApp admin divisi yang tepat.
